# Karma Toolkit 0.11.0

Дата проверки: 30 октября 2026.

## Состав выпуска

Публикуется накопленный набор из 11 навыков: добавлены `karma-debug`, `karma-humanize` и `karma-ui-deslop`; обновлены прежние инструкции и русский README.

- Проектные правила и ссылки на каталог тестов ведутся в `AGENTS.md` с сохранением чужих блоков.
- `karma-tests` при прямом запуске один раз уточняет режим; явно выбранный режим и делегированный аудит не требуют повторного вопроса.
- Аудит не разрешает молча менять код, инструкции проекта или production. Реализация в согласованной области не требует разрешения на каждый шаг.
- `karma-loop` по умолчанию ограничен четырьмя раундами исправлений с итоговым ревью; непрерывный режим включается явно.
- Нагрузка изолируется от реальных данных; очистка не затрагивает чужие ресурсы. Preflight сообщает все независимые блокеры и не считает пропущенную обязательную проверку успехом.
- `karma-humanize` сохраняет исходные редакторские инструкции, справочники и MIT-лицензию. Ревизия источника указана в `UPSTREAM.json`.
- `karma-ui-deslop` содержит 48 пунктов, проверку содержания, сохранение продуктовых действий и сравнение типографики на настоящем фрагменте экрана. Популярный шрифт не запрещён, существующий CSS не равен утверждённому бренду.

## Выполненные проверки

- `quick_validate.py` из установленного `skill-creator`: все 11 навыков прошли проверку структуры.
- `node scripts/validate-toolkit.mjs`: состав, локальные ссылки, 48 уникальных пунктов, метаданные происхождения и наличие лицензии; запуск SessionStart с корректным JSON и без записи файлов.
- `node --check plugins/karma-toolkit/scripts/session-start.js`: синтаксис корректен.
- `claude plugin validate ./plugins/karma-toolkit` и `claude plugin validate ./.claude-plugin/marketplace.json`: пройдены.
- `git diff --check`: ошибок форматирования нет.
- Содержимое `karma-humanize` сверено с Git-объектами указанной upstream-ревизии: лицензия и три справочника идентичны, основной файл идентичен после обратного переименования навыка.
- Прогон новой типографической процедуры на изолированном макете CRM: Manrope, Golos Text, PT Sans; 320, 390, 768 и 1440 px. Проверены совпадение текстов/действий, загрузка шрифтов на кириллице, размеры, поиск, создание контакта, сохранение заметки, ошибка и сохранность черновика при смене статуса.
- Для выбранного макета дополнительно проверены клавиатура, фокус панели, сортировка, выделение, район/статус и переключение темы. Самодостаточный отчёт проверен в sandbox с ограничениями предпросмотра: встроенные изображения, три интерактивных варианта, сохранение и возврат без сетевых запросов и нарушений CSP.

## Границы результата

Проверка упаковки не доказывает правильность решений модели. Типографический прогон выполнен одним автором, без слепого независимого сравнения и пользовательского исследования. Для прежних навыков проверены инструкции и упаковка; новые полноценные модельные прогоны каждого из них в этом выпуске не выполнялись.

Макет использует вымышленные контакты и сохранение только в памяти. Настоящая CRM, её API и данные не изменялись. Физические телефоны, полный набор глифов и полный аудит доступности не проверены. На 768 px в макете остаётся внутренняя горизонтальная прокрутка таблицы.

Хук проверен прямым запуском согласно его exec-конфигурации; новая интерактивная сессия Claude Code с плагином не запускалась. Формат `command` + `args` сверялся с [документацией командных хуков](https://code.claude.com/docs/en/hooks#command-hook-fields). Структура навыков соответствует [руководству OpenAI](https://developers.openai.com/plugins/build/skills).

Проверка маркеров секретов ограничена текущим пакетом и несколькими высокоточными шаблонами; это не полный аудит истории Git. Файлы локального эксперимента, шрифты и снимки экранов не включены в дистрибутив навыка.

## Установка и откат

Устанавливать отдельные навыки из `code0094/karma-toolkit` через `skill-installer`, каталог `plugins/karma-toolkit/skills`, с фиксацией тега `v0.11.0` или полного SHA коммита выпуска.

Перед заменой установленного навыка сохранять предыдущую папку вне каталогов обнаружения навыков. Для отката восстановить такую копию либо установить предыдущую проверенную ревизию. Не откатывать соседние навыки и пользовательские изменения автоматически.
