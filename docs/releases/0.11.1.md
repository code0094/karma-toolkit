# Karma Toolkit 0.11.1

`karma-ui-deslop` переименован в `karma-slop`. Инструкции, 48 пунктов проверки и поведение не изменены. Обновлены имя каталога, метаданные, примеры вызова и путь в валидаторе.

Новый вызов: `$karma-slop`. При обновлении установленного набора старую папку `karma-ui-deslop` следует перенести в резервную копию вне каталога навыков, чтобы не оставлять два одинаковых навыка.

Проверки: валидатор Toolkit, `quick_validate.py`, валидация плагина и маркетплейса, `git diff --check`. Браузерный прогон не повторяется: изменения касаются только имени и упаковки.
